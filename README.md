# PySandboxes

Sandboxes for running untrusted Python code: a Python layer that guards
imports, files, sockets, environment variables, sensitive calls and
dynamically evaluated code, and an OS layer enforced by the kernel.

Nothing has been released yet. This branch carries releases only, so until
the first one the project lives on `develop`:

<https://github.com/pprados/pysandboxes/tree/develop>
