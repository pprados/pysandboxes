**Type:** Monolith

## Project overview

Single-part Python project: sandbox runtime with Python guards and OS-level daemons; CLI `python-sb` and programmatic API (`sandboxes()`, `@sandbox`, `run()`). See [project-overview.md](./project-overview.md).

## Quick reference

- **Tech stack:** Python 3.10+, uv, FastAPI, uvicorn, pytest, ruff, mypy (see [technology-stack.md](./technology-stack.md))
- **Entry point:** CLI `python-sb`; API in `sandboxes_api`
- **Architecture pattern:** Guards + daemons; config-driven rules (see [architecture-patterns.md](./architecture-patterns.md))
