# API Contracts – pysandboxes (main)

**Date:** 2026-03-12  
**Source:** SSE server daemon (internal sandbox execution API)

## Base URL

Internal API served by the sandbox SSE server daemon (not a public HTTP API). Used for remote execution (e.g. `sse_client_subprocess_daemon` calling the server).

## Authentication

- **Scheme:** Bearer token.
- **Header:** `Authorization: Bearer {token}`.
- Token is generated by the daemon and shared with allowed clients; invalid or missing token returns `401 Unauthorized`.

## Endpoints

### GET /ping

- **Purpose:** Health check.
- **Response:** `200 OK`, body `{"message": "OK"}`.

### POST /rpc

- **Purpose:** Execute a function in the sandbox; streams results via Server-Sent Events.
- **Request body:** JSON matching `RPCPayload`:
  - `session_id` (string): Execution session identifier.
  - `function` (string): Callable in `module:function` format.
  - `args` (string): Base85-encoded serialized positional arguments.
  - `kwargs` (string): Base85-encoded serialized keyword arguments.
- **Response:** `200 OK`, `Content-Type: text/event-stream`; SSE stream with stdout/stderr/result or error.
- **Errors:** `401` invalid token; `503` if daemon is stopping (`is_accept_incoming_call()` false).
- **Implementation:** `pysandboxes.remote.sse_server_daemon` (FastAPI app, uvicorn).
