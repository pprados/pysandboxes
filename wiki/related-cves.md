# Related CVEs

Some related CVEs. Selection from the GitHub Advisory Database (pip ecosystem, queried 2026-10-22) of the advisories
that match what PySandboxes confines: code execution and eval injection, sandbox escape, unsafe deserialization, path
traversal and SSRF in agent tools. Denial-of-service, XSS and telemetry advisories are left out.
No such advisory was found for `autogen`, `openai-agents` and `strands-agents`.
